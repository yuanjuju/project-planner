# Changelog

All notable changes to this project are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-12

### Added

- Technology-neutral project planning for greenfield and existing repositories.
- Durable `PROJECT_PLAN.md` and phase specifications under `specs/`.
- Safe merge rules that preserve user-authored planning files.
- Plugin marketplace packaging and standalone skill installation.
- Dependency-free repository validation, regression tests, and CI quality gates.
- Version-controlled trigger-boundary cases and a forward-evaluation protocol.
